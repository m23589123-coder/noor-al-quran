# 📖 نور القرآن (Noor Al-Quran Premium)

![Noor Al-Quran](https://cdn-icons-png.flaticon.com/512/3382/3382152.png)

**منصة قرآنية متكاملة، بتصميم عصري (Glassmorphism) وتجربة استماع استثنائية مستوحاة من كبرى منصات الصوتيات العالمية.**
تم تصميم المنصة لتكون خالية تماماً من الخوادم (Serverless)، تعتمد بالكامل على الـ Frontend وتقنية الـ PWA لتعمل كالتطبيق الأصلي دون الحاجة لإنترنت للملفات المحفوظة.

---

## ✨ الميزات الأساسية (Features)

*   **🎧 مشغل صوتي احترافي:** مستوحى من Spotify، يدعم الاستكمال التلقائي، والتحكم المتقدم من شاشة القفل (Media Session API).
*   **📚 موسوعة التفسير المتقدمة:** تدعم التفاسير المعتمدة (الميسر، السعدي، ابن كثير، الطبري) مع وضع قراءة مريح وتكبير/تصغير الخط.
*   **🏛️ مكتبة العمالقة المصريين:** قسم حصري لرواد التلاوة والتسجيلات النادرة والمحافل.
*   **🔮 محرك توصيات ذكي:** يقترح قراء مشابهين بناءً على خوارزمية الربط في قواعد البيانات.
*   **💾 بدون خوادم (Serverless):** تعتمد كلياً على ملفات `JSON` الخفيفة لتخزين البيانات، وتستخدم `Local Storage` لحفظ الإحصائيات، المفضلة، وقوائم التشغيل.
*   **📱 تطبيق PWA:** جاهز للتثبيت على الهواتف وأجهزة الكمبيوتر مع دعم العمل (Offline).
*   **🎨 تصميم Glassmorphism:** واجهة مستخدم زجاجية فخمة، حركات دقيقة (Micro-animations)، ودعم الوضعين (Dark/Light).
*   **🛠️ أدوات إسلامية:** مسبحة إلكترونية ذكية، ومواقيت الصلاة، وحصن المسلم.

## 🏗️ الهيكل المعماري (Folder Structure)

تم تنظيم المشروع بأفضل الممارسات الهندسية ليكون جاهزاً للنشر المباشر (Production Ready):

```text
noor-al-quran/
├── index.html              # النواة الأساسية للتطبيق
├── manifest.json           # ملف تعريف تطبيق الـ PWA
├── sw.js                   # Service Worker لدعم العمل بدون إنترنت
├── README.md               # توثيق المشروع
├── css/                    # ملفات التصميم
│   ├── style.css           # الأنماط الأساسية والمتغيرات
│   ├── components.css      # تصميم البطاقات والنافبار
│   ├── player.css          # تصميم المشغل الصوتي
│   └── animations.css      # الحركات والمؤثرات البصرية
├── js/                     # المنطق البرمجي (Modules)
│   ├── app.js              # المحرك الرئيسي وربط المسارات (Routes)
│   ├── api.js              # مدير الاتصال بملفات الـ JSON

│   ├── router.js           # نظام التوجيه (SPA Router)
